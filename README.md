# Портфолио Ксении Криштоповой

Статический сайт на Astro + GSAP + Lenis.

## Запуск

Нужен Node.js 22.12 или новее (`node -v`).

```
npm install
npm run dev
```

Сайт откроется на http://localhost:4321

Сборка для проверки: `npm run build`, затем `npm run preview`.

## Где что менять

| Что | Где |
|---|---|
| Все тексты, проекты, навыки, контакты | `src/content/site.ts` |
| Цвета, шрифты, кнопки | `src/styles/global.css` (блок `:root` в начале) |
| Отдельные блоки страницы | `src/components/*.astro` |
| Порядок блоков на главной | `src/pages/index.astro` |
| Страница кейса (общая для всех проектов) | `src/pages/projects/[slug].astro` |
| Анимации | `src/scripts/*.ts`, подключаются в `main.ts` |

Новый проект: скопируй блок проекта в `projects` внутри `site.ts`, поменяй `slug` и тексты. Страница `/projects/<slug>` появится сама.

## Как добавить скрины

Положи файл с нужным именем в папку проекта — он появится на сайте сам, `site.ts` трогать не нужно.
Подходит `.png`, `.jpg` или `.webp`. Нет файла — на сайте аккуратная заглушка.

`public/media/projects/sv-house/`
- `00-cover` — карточка на главной (телефон)
- `01-object` — главная страница объекта
- `02-photo-reports` — фотоотчёты
- `03-stages` — этапы
- `04-budget` — бюджет
- `05-prices` — анализ цен

`public/media/projects/svidno/`
- `00-cover` — карточка на главной (компьютер)
- `01-hero` — первый экран (компьютер)
- `02-economy` — экономика проекта (компьютер)
- `03-mobile` — сайт с телефона

Длинные скрины можно не резать: в макете они прокручиваются.
В режиме `npm run dev` после добавления файла обнови страницу.

Скрины телефона — ширина от 750 px. Скрины сайта — снимок окна 1440 px.
Перед загрузкой скрывай токены, телефоны, имена клиентов.

## Видео

Кладёшь `.mp4` (H.264, до 10 МБ) в `public/media/...` и указываешь путь так же, как для картинок.

## Резюме

Положи `resume.pdf` в `public/` и в `site.ts` напиши `resume: '/resume.pdf'`. Появится кнопка «Резюме».

## Проверка вёрстки

```
npx playwright install chromium   (один раз)
npm run build
npm run preview                   (оставить открытым)
npm run check:layout              (во втором окне)
```

Проверяет ширины 320–1920, пишет FAIL при горизонтальной прокрутке, скриншоты кладёт в папку `shots/`.

## Перед запуском в интернет

1. В `site.ts` поставить `demo: false`.
2. В `public/robots.txt` заменить `Disallow: /` на `Allow: /`.
3. В `astro.config.mjs` вписать настоящий домен в `site`.
